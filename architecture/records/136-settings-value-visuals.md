# 136. 设置页值槽位视觉分层

§129 的行模型(label + value)不变,但三种值渲染成一个样:
Bool 的"开/关"是文字,得读;路径类长值尾部省略,头尾信息
都丢;类型之间没有视觉区分,得靠选中后读详情条。本次是纯
呈现层修订(cue-ui only),Core 模型零改动——类型信息本来
就在 SettingsRow.kind/value 里。

## 决议

```text
Bool     = 开关样式(30×16 轨道 + 12 圆钮):开 = 值蓝
           (0x61afef),关 = 分隔线灰;状态一眼可辨,不占
           文字阅读
Hotkey   = 键帽 chip(深色圆角底 + 值蓝文字),与纯文本值
           拉开层级;捕获中的提示文本保持纯文本(瞬态)
长值     = 中间省略(head/tail 各保留,字符预算 44 ≈
           text_xs @ 320px):路径的头尾都比中间有信息。
           字符计数是启发式,CJK 超宽由布局层尾部省略兜底
详情条   = 上方加 1px 分隔线(与头部同样式),描述文字
           提亮一档(0x9a9aa3 → 0xb0b0b8)——它是"当前行
           说明"区域,不是页脚噪声
明确不做 = 分组标题行(§129 结论不动)、鼠标滚轮/滚动条、
           双栏布局(一个月开一次的页面不值这个体量)
```

## 验证

```text
单测 = middle_ellipsis:短串原样、头尾保留、CJK 按字符计
E2E  = 真机设置页截图:三个 Bool 行开关样式、alt+space 键帽、
       路径全显(未超预算不省略)、详情条分隔线
```
